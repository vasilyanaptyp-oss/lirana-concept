# Lirana, UAB — pagrindinio puslapio koncepcija

Statinis pagrindinio puslapio variantas UAB „Lirana“ (Šilutė): langai, durys, vartai,
roletai, žaliuzės, tinkleliai nuo vabzdžių, markizės ir romanetės, balkono stiklinimas.

Pagrindinė funkcija — gaminio tipo pasirinkimas vienu mygtuku ir angos matmenų įvedimas;
užklausos santrauka atsinaujina realiu laiku.

Tik HTML, CSS ir JavaScript. Jokių sistemų, jokios duomenų bazės.

Duomenys paimti iš įmonės kortelės info.lt.
